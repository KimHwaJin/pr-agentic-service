# 수율

- 수율(yield_pct) = 웨이퍼의 양품 die 수 / 전체 die 수 × 100.
- LOT은 같은 조건으로 함께 진행한 웨이퍼 묶음이다. 수율 비교는 웨이퍼 단위 값을 LOT·설비별로 모아 본다.

## 원인 분석 시 주의
- 설비(eqp_id), 챔버, 공정 조건(압력·온도·RF 전력)과 수율의 관계를 함께 본다.
- 변수 중요도는 "관련이 크다"는 뜻이지 원인을 증명하지 않는다. 상위 변수는 그룹 비교나 회귀로 효과 크기를 확인한다.
- 수율 차이는 평균 차이(%p)와 유의성(p-value)을 함께 보고한다.
