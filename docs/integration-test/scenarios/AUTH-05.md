## 1. 목적
X-User-Id가 없는 사번이거나 형식이 틀리면 거부되는지 확인합니다.

## 2. 사전 조건
- 외부 tenant 키

## 3. 수행 절차
1. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다.
2. 시나리오 **AUTH-05**를 고르고 키를 넣습니다.
3. X-User-Id에 DB에 없는 사번(예: `zz9999`)을 넣고 보냅니다.
4. X-User-Id를 `A B!`로 바꿔 다시 보냅니다.

## 4. 예상 결과
- 3: 403
- 4: 400
