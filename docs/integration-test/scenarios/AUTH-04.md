# AUTH-04 키 + `X-User-Id`로 `GET /users/me`

| 항목 | 값 |
| --- | --- |
| 서비스구분 | AUTH 인증 |
| 우선순위 | P0 |
| 화면 | O 우리 화면만 · API 호출 시험 화면 (감사 로그는 운영) |
| 필요 권한 | 관리자 |
| 단독 수행 | 아니오 |
| 연동 경로 | I2 |
| 11/01판 ID | A4 |

## 1. 목적
키 호출자가 API 키와 X-User-Id로 우리 API를 부를 수 있고, 감사 로그에 남는지 확인합니다.

## 2. 사전 조건
- 외부 tenant 키(it-ext, PREP-09)
- 일반 사용자 A의 사번(한 번 로그인한 사람)

## 3. 수행 절차
1. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다.
2. 시나리오 **AUTH-04**를 고르고 키 원문과 A의 사번을 넣습니다.
3. **요청 보내기**를 누르고 request id를 적습니다.
4. 운영 담당이 로그에서 `api_client_request`와 그 request id를 찾습니다.

## 4. 예상 결과
- 3: 상태 200, 본문 `id`가 A의 사번
- 4: `api_client_request client=<키 이름> tenant=it-ext user=<사번> method=GET path=/api/v1/users/me status=200`

## 5. 확인 방법
API 호출 시험 결과, 로그 검색
