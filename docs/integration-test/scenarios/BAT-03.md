## 2. 사전 조건

## 3. 수행 절차
1. 배치 목록에서 **지금 실행**을 누릅니다.
2. 배치 이름을 눌러 실행 이력 창을 열고, 오른쪽 위 새로 고침으로 상태 변화를 봅니다.
3. 끝난 실행 줄을 눌러 executor 실행 상세 > **개요**를 봅니다.
