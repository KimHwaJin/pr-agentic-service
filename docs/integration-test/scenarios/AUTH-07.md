# AUTH-07 키 개별 폐기

| 항목 | 값 |
| --- | --- |
| 서비스구분 | AUTH 인증 |
| 우선순위 | P0 |
| 화면 | O 우리 화면만 · 폐기는 API 키 탭, 401은 API 호출 시험 화면 |
| 필요 권한 | 관리자 |
| 단독 수행 | 아니오 |
| 연동 경로 | I2 |
| 11/01판 ID | A7 |

## 1. 목적
키 하나를 폐기하면 60초 안에 모든 서버에서 막히는지 확인합니다.

## 2. 사전 조건
- 이 시나리오 전용으로 새로 발급한 키(우리 tenant, 이름 예: it-revoke-test)

## 3. 수행 절차
1. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다. 시나리오 **AUTH-07**을 고르고 새 키로 보내 200인지 봅니다.
2. **시스템 > API 키**에서 그 키를 **폐기**합니다. 시각을 초 단위로 적습니다.
3. API 호출 시험 탭에서 10초 간격으로 다시 보냅니다(키는 다시 붙여 넣기).

## 4. 예상 결과
- 1: 200
- 3: 60초 안에 401 `INVALID_API_KEY`, 그 뒤로 계속 401

## 5. 확인 방법
API 호출 시험 결과의 보낸 시각과 상태
