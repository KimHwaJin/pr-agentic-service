## 1. 목적
실행 중 화면의 중지 버튼으로 run과 executor 실행이 함께 취소되는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인

## 3. 수행 절차
1. 새 대화에서 분석을 요청하고 계획을 승인합니다.
2. 진행 표시가 나오는 동안 전송 버튼 자리의 **중지** 버튼을 누릅니다.
3. **실행 이력**에서 그 실행을 엽니다.

## 4. 예상 결과
- 2: `POST /runs/{id}/cancel` 성공, run 상태 `cancelled`
- 3: executor 실행 상태 `CANCELLED`(또는 `CANCEL_REQUESTED` 뒤 `CANCELLED`)

## 5. 확인 방법
