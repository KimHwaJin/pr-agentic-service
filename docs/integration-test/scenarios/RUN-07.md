## 1. 목적
"추천 말고 새로 만들기"로 새 계획을 받을 수 있고, 허용되지 않은 카드에는 거부되는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인
- 추천될 워크플로우가 있는 상태(PREP-10 시드 또는 RUN-04에서 저장)
- 관리자(422 확인용)

## 3. 수행 절차
1. A가 시드 워크플로우와 비슷한 요청을 보냅니다.
2. 계획 카드에 **추천 말고 새로 만들기** 버튼이 있으면 누릅니다.
3. 버튼이 없는 카드가 뜨면 요청·응답 창에서 그 카드의 `interrupt_id`를 복사합니다.
4. 관리자가 API 호출 시험에서 시나리오 **RUN-07**을 고르고, A의 사번과 세션 ID, 복사한 `interrupt_id`를 넣어 보냅니다(키는 우리 tenant 키).

## 4. 예상 결과
- 2: 같은 run에서 새 계획의 plan_approval 카드가 다시 옴
- 4: 422 `INVALID_ANSWER`(value.action)
