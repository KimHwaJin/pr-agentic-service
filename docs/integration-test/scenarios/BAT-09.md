## 1. 목적
켤 수 없는 배치는 pr-batch가 준 사유가 그대로 표시되고, 켜기가 거부되는지 확인합니다.

## 2. 사전 조건
- BAT-01의 스크립트

## 3. 수행 절차
1. 일정 **수동 실행만**인 배치를 만들고 켜기 버튼 상태와 사유를 봅니다.
2. 일정 **매일 정해진 시각**에 종료 시각을 과거로 둔 배치를 만들고 같은 것을 봅니다.
3. 요청·응답 창에서 두 배치의 `can_enable`, `enable_blocked_reason`을 봅니다.

## 4. 예상 결과
- 1: 켤 수 없음, 사유 `SCHEDULE_REQUIRED`
- 2: 켤 수 없음, 사유 `NO_FUTURE_OCCURRENCE`
- 3: 화면 표시가 응답 값과 같음

## 5. 확인 방법
화면, 요청·응답 창

## 6. 정리 (원상복구)
두 배치 삭제
