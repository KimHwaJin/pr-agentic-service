# AUTH-08 우리 tenant 키를 `own_tenant` 없이 발급

| 항목 | 값 |
| --- | --- |
| 서비스구분 | AUTH 인증 |

| 필요 권한 | 관리자 |
| 단독 수행 | 아니오 |
| 연동 경로 | I2 |
| 11/01판 ID | A8 |

## 1. 목적
우리 tenant 키는 "이 서비스의 tenant" 표시 없이는 발급되지 않는지 확인합니다.

## 2. 사전 조건
- 관리자 로그인

## 3. 수행 절차
1. **시스템 > API 키 > 새 키 발급**을 엽니다.
2. tenant에 `dtest-agent-service`를 넣고 "이 서비스의 tenant로 발급"은 체크하지 않은 채 **발급**을 누릅니다.

## 4. 예상 결과
- 422 오류 메시지, 키가 만들어지지 않음

## 5. 확인 방법
화면 오류 메시지, 요청·응답 창

## 6. 정리 (원상복구)
