## 1. 목적
서비스 사이 키가 틀리면 화면에는 표준 오류가, 로그에는 대상 서비스와 401이 남는지 확인합니다.

## 2. 사전 조건
- 운영 담당(키 설정 변경·재배포)
- **단독 수행**

## 3. 수행 절차
1. 운영 담당이 우리 `BATCH_API_KEY`를 틀린 값으로 배포합니다.
2. A가 **배치** 메뉴를 엽니다.
3. 운영 담당이 우리 로그를 봅니다.
4. 키를 되돌려 배포합니다.

## 4. 예상 결과
- 2: 표준 오류 형식(code, message)과 request id
- 3: pr-batch 호출 401 기록

## 5. 확인 방법
