# RUN-06 `waiting_executor` 중 우리 워커 재시작

| 항목 | 값 |
| --- | --- |
| 서비스구분 | RUN 세션·run 실행 |
| 우선순위 | P0 |
| 화면 | 일부 화면 + 보조 확인 · 워커 재시작은 운영, 결과는 화면 |
| 필요 권한 | 운영 |
| 단독 수행 | 예 |
| 연동 경로 | I3 I5 |
| 11/01판 ID | B6 |

## 1. 목적
executor 결과를 기다리는 중 우리 워커가 재시작돼도, 놓친 이벤트 복구로 run이 끝까지 가는지 확인합니다.

## 2. 사전 조건
- 운영 담당 참석(우리 Pod 재시작 권한)
- 일반 A 로그인

## 3. 수행 절차
1. A가 분석을 요청하고 계획을 승인합니다.
2. "실행 중" 표시가 나오면 운영 담당이 우리 Pod를 재시작합니다. 시각을 적습니다.
3. Pod가 다시 뜨면 A가 화면을 새로 고칩니다.

## 4. 예상 결과
- 재시작 후 120초 안에 run이 이어져 `succeeded`
- 답변과 첨부가 정상

## 5. 확인 방법
화면, 실행 이력, 운영 로그
