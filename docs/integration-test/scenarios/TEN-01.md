# TEN-01 외부 tenant `it-ext` 일괄 폐기 (BAT-10 배치가 켜진 상태)

| 항목 | 값 |
| --- | --- |
| 서비스구분 | TEN tenant·사용자 |
| 우선순위 | P0 |
| 화면 | 일부 화면 + 보조 확인 · 폐기·401은 화면, 외부 tenant 배치 상태는 pr-batch에서 확인 |
| 필요 권한 | 운영 |
| 단독 수행 | 예 |
| 연동 경로 | I6 |
| 11/01판 ID | E1 |

## 1. 목적
외부 tenant를 통째로 폐기하면 키가 막히고, 그 tenant의 배치가 꺼지고, 이미 돌던 실행은 끝까지 가는지 확인합니다.

## 2. 사전 조건
- BAT-10의 it-ext 배치가 켜진 상태
- it-ext 키 원문
- **단독 수행**: it-ext 키를 쓰는 다른 시나리오를 먼저 끝냄

## 3. 수행 절차
1. API 호출 시험에서 it-ext 키로 AUTH-04를 보내 200인지 봅니다.
2. **시스템 > API 키**에서 it-ext 키 줄의 **tenant 전체 폐기**를 누르고 확인합니다. 시각을 적습니다.
3. 알림 문구를 봅니다.
4. 60초 뒤 API 호출 시험에서 같은 요청을 다시 보냅니다.
5. 운영 담당이 pr-batch에서 it-ext 배치의 상태를 봅니다(it-ext 배치는 우리 화면에 안 보임).

## 4. 예상 결과
- 3: "N개 키를 폐기했습니다. pr-batch에서 이 tenant의 배치를 껐습니다." (pr-batch가 안 받으면 "다시 시도하고 있습니다")
- 4: 401
- 5: 배치 꺼짐, `disabled_reason` = `TENANT_REVOKED`. 폐기 전에 제출된 실행은 끝까지 감

## 5. 확인 방법
화면 알림, API 호출 시험 결과, 운영 확인

## 6. 정리 (원상복구)
이후 it-ext가 필요하면 새 키 발급(다시 사용 중이 됨)
