# AUTH-03 브라우저 쓰기 요청에 `X-CSRF-Token` 없음

| 항목 | 값 |
| --- | --- |
| 서비스구분 | AUTH 인증 |
| 우선순위 | P0 |
| 화면 | O 우리 화면만 · API 호출 시험 화면 |
| 필요 권한 | 관리자 |
| 단독 수행 | 아니오 |
| 연동 경로 | I1 |
| 11/01판 ID | A3 |

## 1. 목적
브라우저 쓰기 요청이 CSRF 토큰 없이 거부되는지 확인합니다.

## 2. 사전 조건
- 관리자 로그인

## 3. 수행 절차
1. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다.
2. 시나리오 **AUTH-03**을 고릅니다("이 로그인의 쿠키도 보내기" 켜짐, "X-CSRF-Token 보내기" 꺼짐).
3. **요청 보내기**를 누릅니다.

## 4. 예상 결과
- 상태 403

## 5. 확인 방법
API 호출 시험 결과

## 6. 정리 (원상복구)
없음 (프로젝트는 만들어지지 않아야 함)
