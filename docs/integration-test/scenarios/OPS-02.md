## 1. 목적
Redis가 재시작돼도 컨슈머 그룹이 다시 만들어지고, 놓친 이벤트 복구로 run이 끝나는지 확인합니다.

## 2. 사전 조건
- 운영 담당(Redis 재시작)
- **단독 수행**

## 3. 수행 절차
1. A가 분석을 요청하고 실행 중으로 둡니다.
2. 운영 담당이 Redis를 재시작합니다.
3. 운영 담당이 `XINFO GROUPS executor.events.dtest-agent-service`를 봅니다.
4. A 화면을 지켜봅니다.

## 4. 예상 결과
- 3: 우리 그룹이 다시 있음
- 4: 120초 안에 run 완료
