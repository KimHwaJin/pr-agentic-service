| 항목 | 값 |
| --- | --- |

| 단독 수행 | 예 |

## 1. 목적
tenant의 마지막 사용 중인 키를 하나씩 폐기해도 tenant 폐기와 같이 배치가 꺼지는지 확인합니다.

## 2. 사전 조건
- 외부 tenant(예: it-ext3) 키 1개와 켜진 배치
- **단독 수행**

## 3. 수행 절차
1. **시스템 > API 키**에서 it-ext3 키 줄의 **폐기**(tenant 전체가 아닌 키 하나)를 누릅니다.
2. 운영 담당이 pr-batch에서 배치를 봅니다.

## 4. 예상 결과
- 배치가 `TENANT_REVOKED`로 꺼짐 (pr-batch가 안 받으면 "다시 시도" 알림과 재시도 대기 표시)

## 5. 확인 방법
화면, 운영 확인
