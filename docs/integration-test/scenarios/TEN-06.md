## 1. 목적
비활성화한 사용자를 다시 활성화하면 로그인은 되지만 배치는 꺼진 채인지 확인합니다.

## 2. 사전 조건
- TEN-03 직후

## 3. 수행 절차
1. 관리자가 **시스템 > 사용자**에서 B의 **활성화**를 누릅니다.
2. B가 다시 로그인합니다.
3. B가 배치 목록을 보고 그 배치의 **지금 실행**을 누릅니다.

## 4. 예상 결과
- 2: 로그인 성공
- 3: 배치는 "꺼짐 · 사용자 비활성화" 그대로. 지금 실행은 409 `OWNER_DEACTIVATED`와 "배치를 다시 켠 뒤 실행하세요" 안내

## 5. 확인 방법
화면, 요청·응답 창

## 6. 정리 (원상복구)
