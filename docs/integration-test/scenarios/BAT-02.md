## 1. 목적
일정 있는 배치를 만들면 켤 수 있는 상태가 되고 우리 tenant로 저장되는지 확인합니다.

## 2. 사전 조건
- BAT-01의 스크립트

## 3. 수행 절차
1. **배치 > 새 배치**를 엽니다. 이름, 프로젝트, 스크립트, 런타임을 고르고 일정은 **일정 간격 (분)** 60으로 둡니다.
2. **만들기**를 누릅니다.
3. 배치 목록에서 그 배치의 켜기 버튼 상태를 봅니다.
4. 배치 이름을 눌러 실행 이력 창 제목의 tenant를 봅니다.

## 4. 예상 결과
- 3: **켜기** 버튼이 눌리는 상태(`can_enable: true`)
- 4: tenant `dtest-agent-service`

## 5. 확인 방법
화면, 요청·응답 창의 배치 응답
