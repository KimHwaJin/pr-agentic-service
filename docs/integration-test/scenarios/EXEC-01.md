## 1. 목적
우리 tenant 일반키 + X-User-Id로 executor 실행 목록을 보면 그 사람의 실행만 나오는지 확인합니다.

## 2. 사전 조건
- 우리 tenant 일반키(PREP-09)
- 실행 기록이 있는 일반 A와 B

## 3. 수행 절차
1. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다.
2. 시나리오 **EXEC-01**을 고르고 키와 A의 사번을 넣어 보냅니다.
3. X-User-Id를 B로 바꿔 다시 보냅니다.

## 4. 예상 결과
- 2: 200, 모든 항목의 `context.user_id`가 A
- 3: 모든 항목이 B
