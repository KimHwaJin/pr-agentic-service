# TEN-02 pr-batch를 내린 채 tenant 폐기

| 항목 | 값 |

| 필요 권한 | 운영 |
| 단독 수행 | 예 |
| 연동 경로 | I6 |
| 11/01판 ID | E2 |

## 1. 목적
pr-batch가 내려간 동안 tenant를 폐기해도, pr-batch가 돌아오면 재시도로 배치가 꺼지는지 확인합니다.

## 2. 사전 조건
- 외부 tenant(예: it-ext2) 키와 켜진 배치 1개
- 운영 담당(pr-batch 중지·기동)
- **단독 수행**

## 3. 수행 절차
1. 운영 담당이 pr-batch를 내립니다.
2. **시스템 > API 키**에서 it-ext2의 **tenant 전체 폐기**를 누릅니다.
3. 알림과 키 목록의 표시를 봅니다.
4. 운영 담당이 pr-batch를 올립니다. 시각을 적습니다.
5. 5분 뒤 API 키 탭을 새로 엽니다. 운영 담당이 pr-batch에서 배치를 봅니다.

## 4. 예상 결과
- 3: "pr-batch가 답하지 않아 배치 끄기를 다시 시도하고 있습니다", 키 줄에 "배치 끄기 재시도 대기"
- 5: 표시가 사라짐, 배치 `TENANT_REVOKED`로 꺼짐
