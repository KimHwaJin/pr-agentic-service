# EXEC-03 외부 tenant(`it-ext`) 키로 실행 제출

| 항목 | 값 |
| --- | --- |
| 서비스구분 | EXEC executor 연동 |
| 우선순위 | P0 |
| 화면 | 일부 화면 + 보조 확인 · 제출은 API 호출 시험 화면, PV·스트림은 운영 확인 |
| 필요 권한 | 운영 |
| 단독 수행 | 아니오 |
| 연동 경로 | I2 I3 |
| 11/01판 ID | C3 |

## 1. 목적
외부 tenant 키로 만든 실행은 그 tenant 공간에 생기고, 우리 run에는 영향이 없는지 확인합니다.

## 2. 사전 조건
- 외부 tenant 키(it-ext), 일반 A 사번
- 운영 담당(PV·Redis 확인)

## 3. 수행 절차
1. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다.
2. 시나리오 **EXEC-03**을 고르고 외부 tenant 키와 A의 사번을 넣습니다. `idempotency_key`를 바꿉니다.
3. 보내고 실행 ID를 적습니다.
4. 운영 담당이 PV에서 `tenants/it-ext/…` 아래 생겼는지, 이벤트가 `executor.events.it-ext` 스트림에 쌓였는지 봅니다.
5. A의 대화·실행 이력에 아무 변화가 없는지 봅니다.

## 4. 예상 결과
- 3: 201
- 4: `tenants/it-ext/…`, `executor.events.it-ext`
- 5: 우리 쪽 run 변화 없음, A의 실행 이력에 이 실행이 없음

## 5. 확인 방법
API 호출 시험 결과, 운영 확인, 화면
