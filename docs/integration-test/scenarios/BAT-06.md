# BAT-06 실패하는 스크립트

| 항목 | 값 |
| --- | --- |
| 서비스구분 | BAT 배치 |
| 우선순위 | P0 |
| 화면 | O 우리 화면만 |
| 필요 권한 | 일반 |
| 단독 수행 | 아니오 |
| 연동 경로 | I7 |
| 11/01판 ID | D6 |

## 1. 목적
실패하는 스크립트는 회차가 실패로 끝나고 리포트가 만들어지지 않는지 확인합니다.

## 2. 사전 조건
- 실패용 노트북(PREP-10)

## 3. 수행 절차
1. **배치 > 스크립트 등록**에서 실패용 노트북 파일을 올립니다.
2. 그 스크립트로 **새 배치**(수동 실행만)를 만들고 **지금 실행**을 누릅니다.
3. 실행 이력 창을 봅니다.

## 4. 예상 결과
- 3: 상태 `FAILED`, 상태에 마우스를 올리면 실패 사유
- 리포트 칸이 "-"(리포트 없음)

## 5. 확인 방법
배치 실행 이력, 리포트 탭

## 6. 정리 (원상복구)
배치 삭제
