# BAT-08 우리 워커를 내린 채 배치 성공 → 재기동

| 항목 | 값 |
| --- | --- |
| 서비스구분 | BAT 배치 |
| 우선순위 | P1 |
| 화면 | 일부 화면 + 보조 확인 · 워커 중지는 운영 |
| 필요 권한 | 운영 |
| 단독 수행 | 예 |
| 연동 경로 | I3 |
| 11/01판 ID | D8 |

## 1. 목적
우리 워커가 내려가 있는 동안 끝난 배치도, 다시 뜬 뒤 복구로 리포트가 만들어지는지 확인합니다.

## 2. 사전 조건
- 운영 담당(우리 워커 중지·기동)
- BAT-02 같은 배치

## 3. 수행 절차
1. 운영 담당이 우리 워커를 내립니다.
2. 배치를 **지금 실행**하고 실행이 `COMPLETED`가 될 때까지 기다립니다.
3. 운영 담당이 워커를 다시 올립니다. 시각을 적습니다.
4. 리포트 칸을 봅니다.

## 4. 예상 결과
- 워커 기동 후 10분 안에 리포트 `SUCCEEDED`

## 5. 확인 방법
배치 실행 이력, 리포트 탭
