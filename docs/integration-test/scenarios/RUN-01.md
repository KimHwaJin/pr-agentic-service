# RUN-01 브라우저: 새 세션 + 분석 요청 → plan_approval 승인 → executor 실행 → 리포트

| 항목 | 값 |
| --- | --- |
| 서비스구분 | RUN 세션·run 실행 |
| 우선순위 | P0 |
| 화면 | O 우리 화면만 |
| 필요 권한 | 일반 |
| 단독 수행 | 아니오 |
| 연동 경로 | I1 I3 I5 |
| 11/01판 ID | B1 |

## 1. 목적
사용자가 화면에서 분석을 요청하면 계획 승인을 거쳐 executor에서 실행되고, 결과 리포트가 답변에 붙는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인(AUTH-01)
- 합성 nce 데이터(PREP-10)
- 시스템 > 런타임에 ACTIVE 런타임 1개 이상(PREP-08)

## 3. 수행 절차
1. 왼쪽에서 프로젝트를 고르고 **새 대화**를 엽니다. 모델은 기본값, 코드 레벨은 "기본"으로 둡니다.
2. "nce 데이터 불러와서 기술통계 보여줘"를 보냅니다.
3. "실행 계획 확인" 카드가 뜨면 첫 후보를 그대로 두고 **승인하고 실행**을 누릅니다. 빈 필수 입력이 표시되면 채웁니다.
4. "코드 실행 승인" 카드가 뜨면 승인합니다. 답변이 끝날 때까지 기다립니다.
5. 우측 상단 **요청·응답**을 열어 SSE 이벤트를 봅니다.
6. 왼쪽 **실행 이력**에서 방금 실행을 엽니다.

## 4. 예상 결과
- 3: 카드 종류 plan_approval, 후보 1개 이상
- 4: 답변 아래 리포트(MD)와 노트북(IPYNB) 첨부, "보기"로 열림
- 5: 이벤트에 `execution_completed`, `artifact`가 있고 마지막 run 상태 `succeeded`
- 6: 상태 `SUCCEEDED`, 사용자가 A의 사번, run (metadata.run_id)가 채팅 머리의 run id와 같음

## 5. 확인 방법
채팅 머리의 프로젝트·세션·run id(누르면 복사), 요청·응답 창, 실행 이력 > 개요

## 6. 정리 (원상복구)
