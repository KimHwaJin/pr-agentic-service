## 1. 목적
SSO와 gaia가 사번을 대소문자 다르게 줘도 같은 사용자로 묶이는지 확인합니다.

## 2. 사전 조건
- SSO로 한 번 로그인한 A
- gaia 담당 확인(넘기는 user_id 표기)

## 3. 수행 절차
1. **gaia 화면**(내부망)으로 수행합니다.
2. A로 질문합니다.
3. 관리자가 **시스템 > 사용자**에서 A가 한 명뿐인지 봅니다.

## 4. 예상 결과
