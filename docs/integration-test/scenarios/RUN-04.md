## 1. 목적
실행 중 확인 카드(코드 실행 승인, 질문, 워크플로우 저장)에 답하면 같은 run이 이어지는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인

## 3. 수행 절차
1. 새 대화에서 "LOT별 평균 비교해줘"처럼 정보가 빠진 요청을 보냅니다. "질문" 카드가 뜨면 답을 적고 **답변**을 누릅니다.
2. 계획을 승인하고, "코드 실행 승인" 카드가 뜨면 승인합니다.
3. 분석이 끝나고 "워크플로우 저장" 카드가 뜨면 이름을 확인하고 **저장**을 누릅니다.
4. 요청·응답 창에서 각 응답 요청(`POST /sessions/{id}/runs`)의 응답을 봅니다.

## 4. 예상 결과
- 각 카드 응답이 202 `resumed: true`
- 채팅 머리의 run id가 카드마다 바뀌지 않음
- 3: "워크플로우 저장" 단계 표시, **워크플로우** 메뉴에 새 항목

## 5. 확인 방법
요청·응답 창, 채팅 머리 run id, 워크플로우 목록

## 6. 정리 (원상복구)
3에서 만든 워크플로우는 남겨도 됨(RUN-08에 사용 가능)
