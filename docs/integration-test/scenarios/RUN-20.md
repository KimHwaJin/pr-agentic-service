# RUN-20 같은 이유로 계획이 계속 거부될 때 반복 제한

| 항목 | 값 |

| 필요 권한 | 운영 |

| 연동 경로 | I1 |

## 1. 목적
조건부 호출에 의존한 계획이 거부되면 거부 메시지가 고치는 법을 알려 주고, 반복되면 정해진 횟수(같은 오류 3회, 어떤 오류든 연속 5회) 안에 멈춰 턴이 답변으로 끝나는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인
- 운영 담당(trace·로그 확인)
- AGENT_TOOL_FAILURE_LIMIT 3, AGENT_TOOL_FAILURE_ANY_LIMIT 5(기본)

## 3. 수행 절차
1. 새 대화에서 "nce 데이터를 clean_data로 정리한 결과를 바로 입력으로 써서 LOT별 ANOVA까지 꼭 한 계획으로 묶어줘"를 보냅니다.
2. 계획 카드가 뜨거나 답변이 끝날 때까지 기다립니다. 걸린 시간을 적습니다.
3. 운영 담당이 이 run의 trace(또는 로그)에서 propose_plans 결과를 차례로 봅니다.

## 4. 예상 결과
- 2: 계획 카드(clean_data까지) 또는 답변으로 끝남. 재귀 한도 오류나 무응답이 아님
- 3: 거부 결과가 error 상태이고 "조건부 호출에 의존한 호출을 고치는 법" 안내가 붙음
- 3: 같은 거부가 3회를 넘지 않고, propose_plans 실패가 연속 5회를 넘지 않음([중단됨] 뒤 답변)

## 5. 확인 방법
화면, trace·로그

## 6. 정리 (원상복구)
없음
