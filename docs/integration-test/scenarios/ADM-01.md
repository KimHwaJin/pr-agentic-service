## 1. 목적
API 키 발급·목록·폐기가 되고, 키 원문은 발급할 때 한 번만 보이며, 키 종류가 목록과 응답에 맞게 보이는지 확인합니다.

## 2. 사전 조건
- 관리자 로그인

## 3. 수행 절차
1. **시스템 > API 키 > 새 키 발급**에서 이름 `it-adm01`, tenant `it-adm`, 종류는 기본값(일반키)으로 발급합니다.
2. 발급 창의 키 원문을 확인하고 창을 닫습니다.
3. 목록과 요청·응답 창의 `GET /admin/api-clients` 응답을 봅니다.
4. 그 키를 **폐기**합니다.

## 4. 예상 결과
- 2: 원문이 발급 창에만 보임
- 3: 목록은 키 앞부분(`key_prefix…`)만, 응답에도 원문 없음
- 4: 상태 "폐기"
- 3: 목록 종류 칸 "일반", `GET /admin/api-clients` 응답 `kind: standard`

## 5. 확인 방법
화면, 요청·응답 창
