## 1. 목적
큰 요청과 이미지 한도 초과를 서버가 판단해 화면에 보여 주고, Ingress가 먼저 끊지 않는지 확인합니다.

## 2. 사전 조건
- 이미지 입력 모델이 있는 환경
- 이미지 파일 여러 장(한도보다 1장 많게)과 큰 이미지

## 3. 수행 절차
1. 이미지 입력 모델을 고르고 이미지 첨부 버튼으로 한도보다 많은 이미지를 붙여 보냅니다.
2. 큰 이미지(합계 30MB 정도)를 붙여 보냅니다.

## 4. 예상 결과
- 1: 422와 서버 메시지가 화면에 보임
- 2: 413 또는 422가 우리 서버 응답 형식으로 보임(Ingress의 HTML 오류가 아님)

## 5. 확인 방법
화면, 요청·응답 창
