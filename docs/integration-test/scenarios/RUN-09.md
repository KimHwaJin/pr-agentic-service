## 1. 목적
진행 중인 세션에 새 턴을 보내면 거부되는지 확인합니다.

## 2. 사전 조건
- A의 진행 중인 세션(분석이 돌고 있는 동안)
- 우리 tenant 키

## 3. 수행 절차
1. A가 분석을 요청해 실행 중으로 둡니다. 세션 ID를 채팅 머리에서 복사합니다.
2. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다. 시나리오 **RUN-09**를 고르고 키, A의 사번, 세션 ID를 넣어 보냅니다.

## 4. 예상 결과
- 409 `SESSION_BUSY`

## 5. 확인 방법
API 호출 시험 결과

## 6. 정리 (원상복구)
