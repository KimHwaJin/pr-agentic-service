## 1. 목적
Ingress를 거친 SSE가 토큰을 묶지 않고 바로 흘려보내고, 오래 연결돼도 끊기지 않는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인

## 3. 수행 절차
1. 새 대화에서 긴 답이 나오는 질문(예: "nce 데이터의 컬럼을 하나씩 자세히 설명해줘")을 보냅니다.
2. 답변 글자가 조금씩 나타나는지 봅니다.
3. 대화를 열어 둔 채 6분 기다린 뒤 다른 질문을 보냅니다.
4. 요청·응답 창에서 SSE 항목의 연결 상태를 봅니다.

## 4. 예상 결과
- 2: 글자가 끊김 없이 조금씩 나타남(한꺼번에 몰려 나오지 않음)
- 3: 새 질문의 답이 정상으로 옴
- 4: SSE가 열린 상태를 유지하거나, 끊겼다면 자동으로 다시 연결됨

## 5. 확인 방법
