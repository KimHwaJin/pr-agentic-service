## 1. 목적
gaia access key 검사가 우리 경로는 건너뛰고, gaia 템플릿 API에는 적용되는지 확인합니다.

## 2. 사전 조건
- `GAIA_DEPLOYMENT`가 development 이상인 prd
- gaia 담당에게 받은 템플릿 API 경로 하나

## 3. 수행 절차
1. 우리 화면(`/dev/`)에 브라우저로 로그인합니다.
2. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다. 시나리오 **AUTH-04**를 우리 tenant 키로 보냅니다.
3. 방식 GET, 경로를 gaia 템플릿 API 경로로 바꾸고 키 체크를 끈 채 보냅니다.

## 4. 예상 결과
- 1: 화면이 열림(401 아님)
- 2: 200
- 3: 401 "Access key is required"

## 5. 확인 방법
화면, API 호출 시험 결과
