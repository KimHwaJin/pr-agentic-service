## 1. 목적
환경마다 서비스 사이 키를 새로 만듭니다.

## 2. 사전 조건
- executor 저장소의 `scripts/generate_api_keys.py`를 돌릴 수 있는 담당자

## 3. 수행 절차
1. executor 담당이 `scripts/generate_api_keys.py <env>`로 우리→executor, ops(우리 시스템 화면용), pr-batch→executor 키를 만듭니다.
2. 우리→pr-batch 키는 임의 문자열을 만들고 SHA-256 해시를 구합니다.
3. 키 원문과 해시를 안전한 경로로 각 담당에게 나눕니다.

## 4. 예상 결과
- 키 원문 4개와 해시 4개
- dev와 prd 키가 서로 다름
