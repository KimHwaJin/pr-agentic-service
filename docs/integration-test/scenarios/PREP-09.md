## 1. 목적
관리자 첫 로그인으로 관리자 권한을 받고, 시험용 API 키를 발급합니다.

## 2. 사전 조건
- `ADMIN_EMPLOYEE_IDS`에 관리자 사번이 들어간 상태로 배포됨

## 3. 수행 절차
1. 관리자로 처음 로그인합니다.
2. 왼쪽 아래 이름 옆에 "관리자" 표시와 **시스템** 메뉴가 있는지 봅니다.
3. **시스템 > API 키 > 새 키 발급**에서 우리 tenant 일반키를 만듭니다(tenant `dtest-agent-service`, "이 서비스의 tenant로 발급" 체크, 종류 일반키).
4. 같은 방법으로 우리 tenant 마스터키를 만듭니다(종류 마스터키).
5. 외부 tenant 일반키를 만듭니다(tenant `it-ext`, 체크 안 함, 종류 일반키).
6. 발급 창의 **복사** 버튼으로 키 원문을 복사해 테스트 담당만 보관합니다.

## 4. 예상 결과
- 2: 관리자 표시
- 3~5: 키가 "사용 중"으로 목록에 나오고 종류 칸이 일반·마스터·일반, 원문은 발급 창에만 보임
- 이후 시나리오의 "우리 tenant 키"는 일반키입니다. 마스터키가 필요한 곳은 따로 적습니다.
