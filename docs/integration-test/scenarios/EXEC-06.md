## 2. 사전 조건

## 3. 수행 절차
1. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다.
2. 시나리오 **EXEC-06**을 고르고(X-User-Id 꺼짐) 보냅니다.
3. 방식을 POST, 경로를 `/api/v1/executor/executions`로 바꾸고 EXEC-02 본문을 붙여 보냅니다.
