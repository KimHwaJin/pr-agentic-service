# RUN-21 답변 값이 실제 데이터와 같음(지어낸 데이터 없음)

| 항목 | 값 |
| --- | --- |
| 서비스구분 | RUN 세션·run 실행 |
| 우선순위 | P0 |
| 화면 | 일부 화면 + 보조 확인 |
| 필요 권한 | 운영 |
| 단독 수행 | 아니오 |
| 연동 경로 | I1 I3 I5 |
| 11/01판 ID | - |

## 1. 목적
답변에 나온 통계값이 실제 데이터로 계산한 값과 같고, 커널이 닫힌 뒤에도 np.random 같은 임의 데이터로 결과를 만들어 실제 값처럼 보고하지 않는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인
- 운영 담당이 합성 nce 데이터로 기준값(행 수, SN OPEN의 평균·표준편차, LOT별 평균)을 미리 계산해 둠
- 커널 대기 시간(EXECUTOR_OPERATION_WAIT_SECONDS, 기본 1800초)을 넘겨 기다릴 시간

## 3. 수행 절차
1. 새 대화에서 "nce 데이터 불러와서 행 수와 SN OPEN의 평균·표준편차 알려줘"를 보냅니다. 계획을 승인하고 끝까지 진행합니다.
2. 답변의 값을 기준값과 비교합니다.
3. 답변의 노트북 첨부를 열어 코드에 np.random이나 손으로 만든 DataFrame이 없는지 봅니다.
4. 커널 대기 시간이 지나 실행 이력에서 그 실행이 끝난 것을 확인한 뒤, 같은 대화에서 "아까 데이터로 LOT별 SN OPEN 평균도 보여줘"를 보냅니다.
5. 답변 값과 노트북 코드를 2·3과 같이 봅니다.
6. 1~5를 새 대화에서 두 번 더 반복합니다.

## 4. 예상 결과
- 2: 행 수, 평균, 표준편차가 기준값과 같음(반올림 차이만)
- 3: 데이터는 데이터 로드 tool로 읽음. np.random·임의 생성 DataFrame 없음
- 5: 데이터를 다시 불러와 계산하거나(새 실행) 다시 불러와야 한다고 답함. LOT별 평균이 기준값과 같고, 지어낸 값이 없음
- 6: 세 번 모두 RUN-21-01~03과 같음

## 5. 확인 방법
답변, 노트북, 실행 이력, 기준값
