## 1. 목적
우리 tenant 키를 폐기하면 그 키만 막히고, SSO 사용자의 배치는 그대로인지 확인합니다.

## 2. 사전 조건
- 이 시나리오용 우리 tenant 키(새로 발급)
- A의 켜진 배치

## 3. 수행 절차
1. API 호출 시험에서 그 키로 AUTH-04를 보내 200인지 봅니다.
2. **시스템 > API 키**에서 그 키를 **폐기**합니다.
3. 60초 뒤 같은 요청을 보냅니다.
4. A로 배치 목록을 봅니다.

## 4. 예상 결과

- 4: A의 배치는 켜짐 그대로
