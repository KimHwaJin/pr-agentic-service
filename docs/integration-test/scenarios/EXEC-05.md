# EXEC-05 결과물 `/artifacts/{id}`·`/view/artifacts/{id}`

| 항목 | 값 |
| --- | --- |
| 서비스구분 | EXEC executor 연동 |
| 우선순위 | P0 |
| 화면 | O 우리 화면만 · 외부 tenant 결과물은 API 호출 시험 화면 |
| 필요 권한 | 일반 (외부 tenant 확인은 관리자) |
| 단독 수행 | 아니오 |
| 연동 경로 | I1 I3 |
| 11/01판 ID | C5 |

## 1. 목적
결과물 링크는 프로젝트 멤버만 열 수 있는지 확인합니다.

## 2. 사전 조건
- A의 대화에서 나온 리포트 첨부(RUN-01)
- 일반 B 계정(다른 브라우저 또는 시크릿 창)
- EXEC-03의 외부 tenant 실행 ID(결과물이 있는 실행), 외부 tenant 키, 우리 tenant 키

## 3. 수행 절차
1. A의 답변 첨부에서 **보기** 링크 주소를 복사합니다(`/view/artifacts/<id>`).
2. B로 로그인한 창에서 그 주소를 엽니다.
3. A로 같은 주소를 엽니다.
4. 관리자로 **시스템 > API 호출 시험** 탭을 엽니다. 외부 tenant 키와 A의 사번으로 `GET /api/v1/executor/executions/<EXEC-03 실행 ID>/artifacts`를 보내 artifact ID를 적습니다.
5. 키를 우리 tenant 키로 바꾸고 `GET /api/v1/artifacts/<artifact ID>`를 보냅니다.

## 4. 예상 결과
- 2: 거부(403 또는 404)
- 3: 리포트가 열림
- 5: 거부(403 또는 404), 외부 tenant 결과물이 보이지 않음

## 5. 확인 방법
브라우저 화면, 요청·응답 창
