# OPS-01 executor를 내린 채 분석 요청, 이후 복구

| 항목 | 값 |
| --- | --- |
| 서비스구분 | OPS 장애·설정·부하 |
| 우선순위 | P0 |
| 화면 | 일부 화면 + 보조 확인 · executor 중지는 운영 |
| 필요 권한 | 운영 |
| 단독 수행 | 예 |
| 연동 경로 | I3 |
| 11/01판 ID | G1 |

## 1. 목적
executor가 내려가 있으면 run이 오류로 끝나고 화면이 멈추지 않으며, 복구 후 정상으로 돌아오는지 확인합니다.

## 2. 사전 조건
- 운영 담당(executor 중지·기동)
- **단독 수행**

## 3. 수행 절차
1. 운영 담당이 executor를 내립니다.
2. A가 분석을 요청하고 계획을 승인합니다.
3. 오류 메시지를 봅니다.
4. 운영 담당이 executor를 올리고, A가 새 대화에서 다시 요청합니다.

## 4. 예상 결과
- 3: run이 실패로 끝나고 원인(executor 오류 코드·메시지)과 오류 ID가 보임. 입력창이 다시 쓸 수 있는 상태
- 4: 정상 완료

## 5. 확인 방법
화면, 요청·응답 창

## 6. 정리 (원상복구)
executor 정상 확인(PREP-08 1번)
