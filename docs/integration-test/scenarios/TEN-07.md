## 1. 목적
pr-batch가 내려간 동안 사용자를 비활성화해도, 돌아오면 재시도로 배치가 꺼지는지 확인합니다.

## 2. 사전 조건
- 배치를 켜 둔 일반 사용자(예: C)
- 운영 담당(pr-batch 중지·기동)
- **단독 수행**

## 3. 수행 절차
1. 운영 담당이 pr-batch를 내립니다.
2. 관리자가 C를 비활성화합니다.
3. 알림과 사용자 목록 표시를 봅니다.
4. 운영 담당이 pr-batch를 올립니다.
5. 5분 뒤 사용자 탭을 새로 열고 C 줄의 **배치 보기**를 누릅니다.

## 4. 예상 결과
- 3: "다시 시도하고 있습니다" 알림, C 줄에 "배치 끄기 재시도 대기"
- 5: 표시 사라짐, C의 배치 `USER_DEACTIVATED`로 꺼짐

## 5. 확인 방법
화면

## 6. 정리 (원상복구)
