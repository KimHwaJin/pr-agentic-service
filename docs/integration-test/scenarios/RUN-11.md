# RUN-11 필수 입력을 비우고 승인

| 항목 | 값 |
| --- | --- |
| 서비스구분 | RUN 세션·run 실행 |
| 우선순위 | P1 |
| 화면 | O 우리 화면만 |
| 필요 권한 | 일반 |
| 단독 수행 | 아니오 |
| 연동 경로 | I1 |
| 11/01판 ID | B11 |

## 1. 목적
필수 입력이 비어도 승인 버튼은 막히지 않고, 서버가 그 칸을 짚어 거부하는지 확인합니다.

## 2. 사전 조건
- 일반 A 로그인
- 필수 입력이 있는 계획이 나오는 요청(예: "특정 LOT만 기술통계")

## 3. 수행 절차
1. A가 요청을 보내고 계획 카드를 엽니다.
2. 필수 입력 하나를 비웁니다. tool·skill·계획 옆에 빈 필수 입력 수가 표시되는지 봅니다.
3. **승인하고 실행**을 누릅니다.

## 4. 예상 결과
- 2: 빈 필수 입력 수 표시, 승인 버튼은 눌림
- 3: 422 `INVALID_ANSWER`, 비운 칸 옆에 서버 메시지

## 5. 확인 방법
화면, 요청·응답 창의 `details[].location`

## 6. 정리 (원상복구)
값을 채우고 승인하거나 카드 취소
