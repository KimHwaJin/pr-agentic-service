## 1. 목적
시나리오 전에 서비스 사이 연결이 모두 되는지 5분 안에 확인합니다.

## 2. 사전 조건
- PREP-07 완료, 관리자 로그인 가능

## 3. 수행 절차
1. 관리자로 우리 화면에 로그인해 **실행 이력**을 엽니다.
2. **시스템 > 런타임** 탭을 엽니다.
3. **배치 > 배치 > 새 배치**를 열어 런타임 목록이 나오는지 봅니다.
4. 일정 있는 배치를 하나 만들어 켜기 버튼 옆 표시를 봅니다.
5. 운영 담당이 `XINFO GROUPS executor.events.dtest-agent-service`를 실행합니다.

## 4. 예상 결과
- 1·2: 오류 없이 목록이 나옴
- 3: 런타임이 1개 이상
- 4: `EXECUTOR_NOT_CONFIGURED`가 아님
- 5: 우리 컨슈머 그룹이 있음

## 5. 확인 방법
화면, 요청·응답 창의 상태 코드, Redis 결과

## 6. 정리 (원상복구)
4에서 만든 배치 삭제
