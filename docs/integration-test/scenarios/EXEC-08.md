# EXEC-08 관리자 시스템 > 런타임·점검 탭

| 항목 | 값 |
| --- | --- |
| 서비스구분 | EXEC executor 연동 |
| 우선순위 | P1 |
| 화면 | 일부 화면 + 보조 확인 · 탭은 화면, 키 비우기는 운영 |
| 필요 권한 | 관리자 |
| 단독 수행 | 아니오 |
| 연동 경로 | I1 I4 |
| 11/01판 ID | C8 |

## 1. 목적
관리자 시스템 화면의 런타임·점검 탭이 동작하고, 운영 키가 없으면 그 탭만 503이 되는지 확인합니다.

## 2. 사전 조건
- 관리자 로그인
- 운영 담당(키 설정 변경·재배포)

## 3. 수행 절차
1. **시스템 > 런타임**, **시스템 > 점검** 탭을 엽니다.
2. 운영 담당이 `EXECUTOR_ADMIN_API_KEY`를 비워 배포합니다.
3. 두 탭과 **실행 이력**을 다시 엽니다.
4. 키를 되돌려 배포합니다.

## 4. 예상 결과
- 1: 200, 런타임 목록
- 3: 런타임·점검 탭만 503 오류, 실행 이력은 정상

## 5. 확인 방법
화면, 요청·응답 창
