# TEN-03 사용자 B 비활성화

| 항목 | 값 |
| --- | --- |
| 서비스구분 | TEN tenant·사용자 |
| 우선순위 | P0 |
| 화면 | O 우리 화면만 · 시스템 > 사용자 > 배치 보기 |
| 필요 권한 | 관리자 |
| 단독 수행 | 예 |
| 연동 경로 | I1 I6 |
| 11/01판 ID | E3 |

## 1. 목적
관리자가 사용자를 비활성화하면 30초 안에 SSO·키 접근이 모두 막히고, 그 사람의 배치가 꺼지는지 확인합니다.

## 2. 사전 조건
- 일반 B가 일정 있는 배치를 켜 둠(B로 BAT-02)
- B가 다른 브라우저에 로그인해 있음
- **단독 수행**: B 계정을 쓰는 시나리오를 먼저 끝냄

## 3. 수행 절차
1. B 브라우저에서 배치가 켜짐인지 봅니다.
2. 관리자가 **시스템 > 사용자**에서 B를 검색하고 **비활성화**를 누른 뒤 확인합니다. 시각을 적습니다.
3. 알림 문구와 아래에 열린 B의 배치 목록을 봅니다.
4. 30초 뒤 B 브라우저를 새로 고칩니다.
5. API 호출 시험에서 우리 tenant 키 + B 사번으로 AUTH-04를 보냅니다.

## 4. 예상 결과
- 3: "pr-batch에서 배치를 껐습니다", B의 배치 "꺼짐 · 사용자 비활성화"(`USER_DEACTIVATED`)
- 4: 로그인 화면 또는 401/403
- 5: 403

## 5. 확인 방법
화면, API 호출 시험 결과

## 6. 정리 (원상복구)
TEN-06으로 이어서 재활성화
