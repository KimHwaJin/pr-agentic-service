## 1. 목적
배치가 성공하면 리포트가 만들어지고 노트북 마지막 셀에 붙는지 확인합니다.

## 2. 사전 조건
- BAT-03에서 성공한 실행

## 3. 수행 절차
1. 배치 실행 이력 창에서 그 실행의 리포트 칸을 봅니다(대기 중이면 몇 분 기다림).
2. 리포트를 엽니다.
3. 노트북 칸의 **보기**를 눌러 마지막 셀을 봅니다.
4. **배치 > 리포트** 탭에서도 확인합니다.

## 4. 예상 결과
- 1: 리포트 상태 성공(`SUCCEEDED`), 최대 30분 안
- 2: 리포트 내용이 열림
- 3: 마지막 셀에 리포트 markdown
- 4: 목록에 같은 리포트, `artifact_id` 있음

## 5. 확인 방법
화면, 요청·응답 창의 `/batch-reports` 응답
