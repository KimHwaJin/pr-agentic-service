## 1. 목적
처음 로그인한 사용자가 소문자 사번으로 만들어지고 기본 프로젝트를 받는지 확인합니다.

## 2. 사전 조건
- 한 번도 로그인한 적 없는 일반 사번

## 3. 수행 절차
1. 브라우저(Chrome 또는 Edge)로 우리 화면 주소(`https://<host>/dev/`)를 엽니다.
2. SSO 로그인을 마칩니다.
3. 우측 상단 **요청·응답**을 열고 `GET /api/v1/users/me` 응답을 봅니다.
4. 왼쪽 **프로젝트** 메뉴를 엽니다.

## 4. 예상 결과
- 2: 우리 화면으로 돌아옴
- 3: `user.id`가 소문자 사번
- 4: 기본 프로젝트 1개

## 5. 확인 방법
요청·응답 창, 프로젝트 목록
